# Химия с пониманием

Бесплатный учебный портал Ростислава Ковалевского: база реакций, интерактивные тренажёры, «Формула дня» и конструктор органических структур.

**[Открыть портал →](https://rpkovalevskiy.github.io/)**

## Что есть на сайте

| Раздел | Что можно делать |
| --- | --- |
| [Неорганическая химия](https://rpkovalevskiy.github.io/inorganic/) | Искать вещества и реакции, изучать карточки и тренироваться |
| [Формула дня · Fordle](https://rpkovalevskiy.github.io/fordle/) | Каждый день угадывать новую химическую формулу за шесть попыток |
| [Органический конструктор](https://rpkovalevskiy.github.io/organic/structures/) | Собирать структурные формулы из атомов и связей и проверять решения заданий |
| [Каталог органических заданий](https://rpkovalevskiy.github.io/organic/structures/catalog.html) | Выбирать задания и видеть свой прогресс |

Портал помогает изучать химию и готовиться к ЕГЭ. Все инструменты работают в браузере без регистрации.

## Как сохраняется прогресс

Попытки и статистика «Формулы дня», выполненные задания и черновики органического конструктора сохраняются в браузере на текущем устройстве.

Между устройствами и браузерами прогресс автоматически не синхронизируется. Очистка данных сайта удаляет сохранения.

## Обратная связь

Нашли ошибку в реакции, условии задания или работе тренажёра? Есть идея, как сделать портал удобнее?

[Создайте обращение в Issues](https://github.com/rpkovalevskiy/rpkovalevskiy.github.io/issues). Приложите ссылку на страницу или номер задания и опишите, что нужно исправить. Если речь о химическом содержании, будет полезен источник или объяснение.

## Локальный запуск

В репозитории находятся готовые статические файлы сайта.

Если установлен Python, откройте терминал в папке репозитория и выполните:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000/.

### About this project

A free Russian-language chemistry learning portal with a reaction database, interactive exercises, a daily formula puzzle, and an organic molecule editor.

The website runs in the browser without registration. Learning progress is stored locally on the user's device.
